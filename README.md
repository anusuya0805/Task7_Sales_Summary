# Sales Summary Analysis using SQLite and Python

## Project Overview

This project demonstrates how Python can be combined with SQLite and SQL to analyze sales data and generate a simple business-oriented sales summary.

The project uses SQL queries to calculate product-level sales quantities and revenue, then uses Python and Pandas to process the results and Matplotlib to visualize the analysis.

---

## Problem Statement

Businesses often need to quickly understand how their products are performing.

Raw sales records alone do not provide an immediate view of:

- How much of each product was sold
- How much revenue each product generated
- Which products contributed more to overall sales

This project addresses this problem by transforming raw sales records into a summarized view of product quantity and revenue.

---

## Project Objective

The main objectives of this project are to:

- Store sales data in a SQLite database
- Use SQL to summarize sales information
- Calculate total quantity sold for each product
- Calculate total revenue for each product
- Load SQL results into a Pandas DataFrame
- Visualize product-level revenue
- Demonstrate a basic end-to-end data analysis workflow

---

## Business Use Case

A sales team or business analyst can use this type of analysis to understand basic product performance.

The summarized information can help answer questions such as:

- Which products generate more revenue?
- How much quantity has been sold for each product?
- How does revenue differ across products?
- Which products may require further analysis?

Although this is a small analytical project, the workflow represents a common pattern used in data analytics:

**Raw Data → SQL Analysis → Summary Metrics → Visualization → Business Insight**

## Analysis Workflow

The project follows these steps:

1. Created a SQLite database containing sales records.
2. Connected Python to the SQLite database.
3. Used SQL to calculate product-level sales metrics.
4. Calculated total quantity sold.
5. Calculated total revenue using quantity × price.
6. Grouped the results by product.
7. Loaded the SQL results into a Pandas DataFrame.
8. Reviewed the summarized sales information.
9. Created a bar chart to visualize revenue by product.
10. Saved the visualization as an image.

## Limitations

This project uses a small sales dataset and focuses on basic product-level analysis.

The analysis does not include:

- Customer-level analysis
- Regional analysis
- Monthly sales trends
- Profitability analysis
- Product category analysis
- Customer segmentation
- Forecasting
- Advanced statistical analysis

Therefore, the project is intended as a demonstration of SQL-based sales summarization and Python integration rather than a complete sales analytics system.
